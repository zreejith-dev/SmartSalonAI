# SmartSalon AI

### AI-Powered Salon Operating System

**Status:** 🔄 In Progress · **Year:** 2026

An AI salon OS that remembers every customer's exact haircut history — designed as a real pilot for a Kerala salon, from a 36-section PRD down to a Supabase-backed live MVP.

## What It Is

SmartSalon AI turns a salon into an intelligent business. Every customer's haircut history, preferences, and appointment patterns are remembered automatically — so the next visit starts with the stylist already knowing what to do.

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Frontend | **Flutter** |
| Backend / DB | **Supabase** |
| Process | PRD → MVP (36-section product requirements doc) |

## Key Features

- **Customer history memory** — exact haircut records per customer
- **Smart booking** — remembers preferences and patterns
- **AI assistance** — recommendations based on past visits
- **Real pilot** — designed for an actual Kerala salon
